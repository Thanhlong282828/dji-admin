# Data Anonymization Governance

Deletion removes data; redaction suppresses display/log output; masking replaces presentation; pseudonymization retains a controlled re-identification link; anonymization is intended to be irreversible.

Phase 3F-22 does not claim anonymization and performs none. A future policy must identify fields, linkage risk, checksum/history impact, tenant ownership and legal authority before an owning module can implement a transformation. Reversible identifiers must never be reported as anonymized.
