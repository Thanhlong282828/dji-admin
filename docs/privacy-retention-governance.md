# Privacy Retention Governance

Every future retention rule must name classification, data owner, retention basis, archive policy and deletion eligibility. Legal durations are deliberately unset until approved.

- Employee termination does not imply deletion.
- Employment, Payroll, tax, accounting and audit histories remain immutable where the owning domain requires retention.
- Consent withdrawal preserves historical evidence and blocks only processing governed by that purpose.
- Corrections append evidence; they do not rewrite immutable history.
- Data-subject access should return category inventory for the authorized employee/company only, excluding secrets, other employees and internal security metadata.

No production record is deleted, anonymized, exported or re-encrypted by this phase.
