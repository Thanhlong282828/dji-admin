# Legal Hold Governance

An active hold contains a technical reference, scope, resource type, reason category, start/release timestamps, status and authority reference. Sensitive legal narrative is deliberately excluded.

Active hold precedence is unconditional for hold-eligible policy: it blocks archive/disposal eligibility even when retention has elapsed. Release and disposal are separate high-risk actions and must eventually use maker-checker controls. Phase 3F-22 provides typed evaluation and tests only; it creates no production hold and no persistence table.
