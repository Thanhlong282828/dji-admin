# Enterprise Reporting Design

## Flow

`EnterpriseReportController` validates tenant and permissions, creates `ReportingFilter`, calls `EnterpriseReportingService`, and returns `EnterpriseReportViewModel` to preview or `EnterpriseReportExportService`. The typed `EnterpriseReportCatalog` owns report titles, categories, formats, classification and descriptions.

## Board Pack

The board pack includes Executive, Workforce, Attendance/Leave, Recruitment, Payroll/Compensation when authorized, Planning Execution, Workflow/IAM and Data Quality sections. It includes company, selected period, generated time, schema version and data-source quality status. Notes are deterministic facts only.

## Formats

- HTML: responsive black-gold preview with accessible text/table fallback.
- CSV: UTF-8 BOM, bounded flattened aggregate rows, formula-safe cells.
- XLSX: one sheet per available section, frozen headings, no external links.
- PDF: local Dompdf rendering, embedded safe styles, no external fonts/network.

Every generated byte payload receives an actual SHA-256 checksum header. No artifact is persisted or described as certified.

## Privacy and ownership

Workforce reports contain aggregate labels only. Restricted financial sections are omitted before rendering/export when permission is absent. Corrections happen through the owning Organization, Employee, Attendance, Leave, Recruitment, Payroll, IAM or Workflow menu and the live report is regenerated.
