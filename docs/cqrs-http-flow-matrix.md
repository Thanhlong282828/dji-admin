# CQRS HTTP Flow Matrix

This matrix records the runtime flows hardened in the unified operating-system audit. The complete route inventory remains generated by `php artisan route:list`; this document focuses on business-significant integration boundaries.

| Route/use case | Type | Request/controller | Message/bus | Handler | Service/repository | Canonical writes/reads | Downstream |
|---|---|---|---|---|---|---|---|
| Company index/detail | READ | `CompanyController` | Company queries / QueryBus | Company query handlers | Company read repository | companies, branches, sellers | Company views |
| Company create/update | WRITE | typed Company requests | Company commands / CommandBus | Company handlers | Company repositories + seller account service | company + inline branches/sellers transaction | Branch/Seller views |
| Seller governance index | READ | `Modules/Commerce/.../SellerGovernanceController` | `Modules/Commerce/.../GetSellerGovernanceQuery` / QueryBus | `GetSellerGovernanceHandler` | scoped aggregate read | seller_profiles/users/stores | governance view |
| Seller transition | WRITE | validated status/reason | `ChangeSellerGovernanceStatusCommand` / CommandBus | `ChangeSellerGovernanceStatusHandler` | `SellerGovernanceService` | seller_profiles + activity audit | Company/Seller/Store access |
| POS warehouse | READ | `Modules/POS/.../BranchCommerceController` | `Modules/POS/.../GetBranchCommercePageQuery` / QueryBus | `GetBranchCommercePageHandler` | `BranchCommerceReadService` | products/variants/media/inventory | warehouse view |
| POS customers/services | READ | same | same | same | same | commerce_customers/company_services + history counts | CRM/service views |
| POS customer/service CRUD | WRITE | explicit validated fields | `MutateBranchCommerceCommand` / CommandBus | `MutateBranchCommerceHandler` | `BranchPosService` | canonical customer/service tables | check-in/options/history |
| POS check-in | WRITE | validated branch/customer | `MutateBranchCommerceCommand` | same | `BranchPosService::checkIn` | customer_visits | Checkout |
| POS line add/remove | WRITE | validated service/product/quantity | same | same | BranchPosService | visit snapshot lines | checkout totals |
| POS checkout | WRITE | validated internal payment evidence | same | same | BranchPosService + InventoryService transaction | inventory balance/movement + receipt + recognized revenue + visit | Sales, Finance, Dashboard |
| POS sales | READ | BranchCommerceController | `GetBranchCommercePageQuery` | handler | read service | receipt + customer + revenue | Sales view |
| Executive dashboard | READ | DashboardController | dashboard queries / QueryBus + justified bounded service | handlers | Dashboard repository + BranchDashboardReadService | canonical HR, Order, Receipt, Customer, Inventory, Revenue, Finance | dashboard cards/charts |
| Payroll input/run | WRITE/READ | Payroll controllers/requests | Payroll commands/queries | Payroll handlers | Payroll domain services/repositories | versioned input/run/item sources | Payslip/Tax/Accounting/Finance |
| Branch Finance | READ | finance controllers | justified read service | — | BranchFinancialPerformanceService | recognized revenue + finalized payroll + OPEX/rent/assets | Finance/dashboard/reporting |
| Article create/update | WRITE | `Modules/Article/.../ArticleController` | `SaveArticleCommand` / CommandBus | `SaveArticleHandler` | `ArticleWriteService` + MediaService | article + owned media + activity evidence | Admin/public Article views |
| Account Security | READ | `Modules/Iam/.../AccountSecurityController` | `GetAccountSecurityQuery` / QueryBus | `GetAccountSecurityHandler` | IAM scoped read model | identity, company/branch access, seller/buyer, OAuth summary | Account Security view |

## Verified controller rule

POS, Seller, Product, Branch, Article and IAM profile mutations contain no controller persistence. Controllers validate/authorize and dispatch Commands or invoke already-governed application boundaries; architecture audit enforces zero Presentation CQRS violations.
