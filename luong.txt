FILE-TO-FILE WIRING MAP — CÚ PHÁP FILE | FUNCTION | BIẾN
======================================================================

Cách đọc:
`file A | functionA($biến)` → `file B | functionB($biến)` nghĩa là function trong file A tạo/truyền biến sang function ở file B.
`$commands->dispatch($command)` và `$queries->ask($query)` đi qua Core Bus; Bus tìm Handler theo convention tên class.

1. CORE BUS
Modules/Core/app/Application/Buses/LaravelCommandBus.php | dispatch(object $command)
→ lấy `$messageClass = $command::class`
→ đổi `Command` thành `Handler` trong biến `$handler`
→ Container::make($handler)
→ Handler | handle($command).
Modules/Core/app/Application/Buses/LaravelQueryBus.php | ask(object $query)
→ lấy `$messageClass = $query::class`
→ đổi `Query` thành `Handler` trong `$handler`
→ Container::make($handler)
→ Handler | handle($query).
