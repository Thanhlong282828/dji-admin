# 11. HIRE CANDIDATE

`HireCandidateCommand` phải thực hiện transaction hoàn chỉnh.

Luồng:

```text
Application ở stage offer
→ kiểm tra offer accepted hoặc rule tương đương
→ kiểm tra vacancy
→ tạo Employee
→ tạo employee_code
→ liên kết Company
→ tạo primary assignment
→ tạo employment contract draft hoặc active theo policy
→ tạo Onboarding Case
→ cập nhật Application stage = hired
→ cập nhật Requisition vacancy progress
→ đánh dấu Requisition filled nếu đủ số người
→ tạo EmployeeHistory nếu cần
→ dispatch CandidateHired
→ clear cache
→ activity log
→ notification
→ broadcast
```

## Business rules

* Không tạo Employee trùng Candidate đã hire.
* Phải idempotent.
* Nếu request gửi lại không được tạo hai Employee.
* Phải khóa Application hoặc Requisition khi xử lý để tránh race condition.
* Phải dùng transaction.
* Nếu bất kỳ bước nào lỗi thì rollback toàn bộ phần database.
* Không tự động tạo User có password mặc định.
* Có thể tạo invitation riêng sau khi hire.
* Employee code phải sinh theo convention project.
* Company và Job Position phải lấy từ Requisition.
* Assignment phải đúng Organization Unit.
* Manager lấy theo cấu hình hoặc yêu cầu người dùng chọn.
* Không vượt approved headcount nếu thiếu override permission.

Tạo service:

```text
CandidateHiringService
EmployeeCodeGenerator
HiringIdempotencyService
```
