[BUSINESS FLOW] Company → Vendor → Procurement → Goods Receipt → Inventory → Vendor Bill → AP → Treasury → Accounting → Financial Statements
[BUSINESS FLOW] Commerce → Customer → Quotation → Sales Order → Inventory Fulfillment → COGS → Customer Invoice → AR → Collection → Treasury → Accounting → Financial Statements
[BUSINESS FLOW] Marketplace → Payment → Fulfillment → Inventory → COGS → Revenue → Finance
[BUSINESS FLOW] POS → Receipt → Customer History → Inventory → COGS → Revenue → Finance
[BUSINESS FLOW] Employee / Procurement / Finance / Commerce → Enterprise Document → immutable Version + SHA-256 → Workflow / Approval Inbox → Notification / Audit → owner-domain Command
[BUSINESS FLOW] Finance Asset → Assignment → Depreciation → Accounting → Financial Statements
[BUSINESS FLOW] Expense → Approval → Treasury → Accounting → Budget Actual
[BUSINESS FLOW] Budget → Commitment → Procurement / Expense → Actual → Budget vs Actual
[BUSINESS FLOW] Source domains → SourceAccountingPostingService → Journal → GL → Trial Balance → Financial Statements
